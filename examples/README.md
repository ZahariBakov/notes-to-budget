# Examples / Примери

Invented notes that show the format. They match the starter settings that
`notes-to-budget init` creates, so you can try the program right away:

```
notes-to-budget init my-budget --language en
notes-to-budget read-notes examples/en/notes/March-2026.txt --data-folder my-budget --show-entries
```

Измислени записки, които показват формата. Отговарят на примерните настройки
от `notes-to-budget init`, така че можеш да пробваш програмата веднага:

```
notes-to-budget init моят-бюджет --language bg
notes-to-budget read-notes examples/bg/notes/Март-2026.txt --month 2026-03 --data-folder моят-бюджет --show-entries
```

The first line of every day holds the balances **in the morning**: cash /
online wallet / bank card. The numbers in these examples add up, day by day.

Първият ред на всеки ден са наличностите **сутринта**: кеш / онлайн портфейл /
банкова карта. Числата в примерите излизат точно, ден по ден.
